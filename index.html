⏰ 活动记录与提醒

到点后页面顶部会弹出醒目提醒并播放提示音（浏览器限制：请先点击页面任意位置以启用声音）。上课预告：每节课开始前 10 分钟自动弹窗预告。可分别选择「提醒音效」与「响铃时长」（单次 / 多次 / 持续若干秒 / 一直响），切换即试听；响铃过程中可随时点「停止响铃」，关闭提醒横幅也会立即停止。

📥 批量导入课程

直接上传教务系统导出的表格即可，会自动识别并导入，无需整理格式：
· 文件类型：.xlsx / .xls / .csv / .txt（CSV 自动识别 UTF-8 与 GBK 编码，不会乱码）
· 列顺序随意，表头名称可模糊匹配（课程名称 / 任课教师 / 教室名称 / 上课星期 / 上课节次 / 上课周次 / 课程性质 / 备注等）；也支持「开始周 + 结束周」两列
· 表格上方有标题行也能识别（自动定位表头在第几行）；多个工作表会自动挑出最像课表的那一个
· 完全没有表头时，会按单元格内容自动推断各列（并提示推断结果供核对）
· 课表网格（星期横排、节次竖排的格子式课表）也能识别，格子里写「课程 / 教师 / 地点 / 周次」即可，未标注周次按全学期处理
· 周次支持多段与单双周（如 3-4周,6-18周、7-17周(单)）；节次支持跨大节（如 5-10节），会自动按大节拆分
支持 SheetJS 在线解析，若离线无法加载，请使用下方文本粘贴方式。

方式二：文本粘贴

支持中英文逗号 / Tab 分隔（可直接从 Excel 复制粘贴），每行一门课；末尾可加「考试」标记为考试安排；格式错误或时间冲突的行会跳过并提示。
